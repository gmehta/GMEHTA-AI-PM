Enterprise Search

Hybrid retrieval over the (mock) company knowledge base — lexical BM25 fused with real semantic embeddings computed in your browser (MiniLM-L6-v2 via transformers.js, no server). Try “how many vacation days do I get” — semantic search finds the PTO policy without keyword overlap.

Integrations

The front door is only as good as its action layer. Each connector is registered with typed tools, least-privilege scopes, and policy gates — the agent can act everywhere the employee can, and nowhere they can't.

Governance model

Three gates before any write-action executes: ① identity (the agent inherits the employee's entitlements — permission-aware retrieval and action), ② policy (declarative rules, e.g. "hardware spend above standard config → manager approval"), ③ human-in-the-loop (irreversible or financially material actions pause for explicit approval). Every step emits an audit event. This is the moat over consumer-grade assistants — and the reason the assistant is approved for Confidential data while external AI tools are not.

About this demo

Live Mode (bring your own key)

By default this demo replays scripted agentic flows. Paste an Anthropic API key to switch the assistant to a real agentic loop — Claude plans, calls the same mock enterprise tools, hits the same approval gates, and answers grounded in the same corpus. The key stays in your browser's memory only (never stored, never sent anywhere except api.anthropic.com).

Calls are made directly from your browser with the anthropic-dangerous-direct-browser-access header. Suitable for demos only — production would proxy through a governed backend.
