Bring your own coding agent

The other half of Studio: engineers and AI agents who would rather build in their own tools get the same substrate through a spec, a CLI, and MCP tools. Build an app in the Studio tab first, then see it here as code — two paths, one product.

Build an app in the Studio tab first — its spec, CLI workflow, and MCP surface will show up here.

Why this matters

Every app built in the visual builder is also a spec an agent can pull, edit, and push back; every app built by an agent renders in the visual builder for refinement. Neither path is a second-class citizen — the seam is the product. The free tier keeps BYO-agent access rate-limited but open, because the builders who arrive with their own agents are the ecosystem's most influential users.

About this demo

Live Mode (bring your own key)

Scripted mode replays three pre-built apps. Paste an Anthropic API key and the prompt bar becomes real: Claude generates a working app from any prompt against the mock platform APIs, renders it live, and refines it conversationally. The key stays in browser memory only (sent only to api.anthropic.com).

Demo-only pattern via anthropic-dangerous-direct-browser-access; production would proxy through a governed backend.
